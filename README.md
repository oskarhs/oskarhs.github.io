# oskarhs.github.io

Source for my personal website, served via GitHub Pages at
<https://oskarhs.github.io>.

## Local preview

```bash
python3 -m http.server
# then open http://localhost:8000
```

## Structure

- `index.html` — the page
- `style.css` — styling
- `.nojekyll` — tells GitHub Pages to serve files as-is (no Jekyll build)
